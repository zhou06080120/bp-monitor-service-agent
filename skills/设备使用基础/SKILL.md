# 设备使用基础

## 适用场景
用户询问设备本身的操作与规格：开机/关机、待机自动关机、充电与续航、电量提醒、屏幕错误代码、历史记录存储、充电指示灯、型号功能差异（是否支持蓝牙/APP）。

## 回答要点（直接引用政策事实，不要推脱给人工）

### 开机与关机
- 长按电源键 **3秒** 开机；短按电源键 **1秒** 关机。
- 开机后进入待机，待机超时 **5分钟** 自动关机。
- 低电量提醒：电量低于 **15%** 屏幕闪烁；低于 **5%** 自动关机。

### 电池与充电
- 内置锂电池，满电续航约 **300次测量**。
- 使用原装充电器约 **2小时** 充满。
- 充电指示灯：**红灯=充电中**，**绿灯=已充满**。
- 电池不可自行拆卸，需联系售后更换。

### 屏幕错误代码
- **E1** = 袖带未绑紧
- **E2** = 测量中移动
- **E3** = 气路漏气
- **E4** = 电池电量不足

### 历史记录存储
- 设备端最多存储 **90组** 数据，超出自动覆盖最早记录；APP 端历史数据永久保存。

### 型号差异（是否支持蓝牙/APP）
- **KP-100**：基础款，仅臂式，**无蓝牙，无法连接 APP**。
- **KP-200**：臂式+蓝牙，支持双用户。
- **KP-300**：臂式+腕式双模式，蓝牙+WiFi，支持 4 用户。
- 仅 **KP-200 及以上** 型号支持 APP 同步。
