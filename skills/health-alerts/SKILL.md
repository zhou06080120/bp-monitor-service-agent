# 异常读数与健康提醒

## 高血压分级
| 分级 | 收缩压(mmHg) | 舒张压(mmHg) |
|------|-------------|-------------|
| 正常 | <120 | <80 |
| 正常高值 | 120-139 | 80-89 |
| 1级高血压(轻度) | 140-159 | 90-99 |
| 2级高血压(中度) | 160-179 | 100-109 |
| 3级高血压(重度) | ≥180 | ≥110 |
- 收缩压 ≥**180** 或舒张压 ≥**110** 时 APP 弹出 **紧急就医提醒**
- 单次偏高不等于高血压，需 **不同日3次** 测量均超标方可确诊

## 低血压判断
- 低血压标准：收缩压 **<90 mmHg** 或舒张压 **<60 mmHg**
- 低血压伴随头晕/乏力时建议就医
- APP 不会因低血压触发紧急提醒，仅标注"偏低"

## 异常心率提醒
- 心率 **<60次/分** 标注"心动过缓"
- 心率 **>100次/分** 标注"心动过速"
- 心率 **>160次/分** 或 **<40次/分** 时弹出"建议立即就医"提醒
- 心律不齐检测到不规则脉搏时标注"请重新测量"

## 紧急情况建议
- 收缩压 ≥180 或舒张压 ≥110 并伴随头痛/胸闷：**立即拨打120**
- 测量结果持续异常（连续3天偏高）：建议 **48小时内** 就医
- APP 紧急提醒仅为参考，不替代专业医疗判断
- 设备不适用于 **孕妇、严重心律不齐、血液循环障碍** 患者日常监测

## 回答原则
以上问题均有明确答案，应直接作答，不要转人工客服。
